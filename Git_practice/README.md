# Эмулятор оболочки ОС (Вариант №4)

Дисциплина: Конфигурационное управление (3 семестр, 2026/2027)

## 1. Общее описание
Данное приложение является консольным эмулятором языка оболочки ОС (шелл), имитирующим работу в командной строке UNIX-подобной ОС поверх виртуальной файловой системы (VFS), загружаемой из XML-файла.
